AM-GM Inequality: Traps, Counterexamples & Visual Proofs

수학(하) 절대부등식 핵심 마스터

"공식만 외워서 대입하면 100% 함정에 빠집니다!"

산술·기하평균 부등식은 최대·최소 문제에서 가장 강력한 도구이지만, 세 가지 전제 조건을 하나라도 간과하면 엉뚱한 오답을 내게 됩니다.

기본 정리 (AM-GM Inequality)
$$\frac{A+B}{2} \ge \sqrt{AB} \quad (A+B \ge 2\sqrt{AB})$$
(단, $A>0, B>0$ 이고 등호는 $A=B$ 일 때 성립)

🚨 산술·기하평균 적용 전 반드시 확인해야 할 3대 원칙

문제 풀이를 시작하기 전, 아래의 세 가지 조건을 단계별로 검증하는 습관을 들여보세요.

01
전제 조건

양수 조건 ($A>0, B>0$)

산술기하평균은 두 대상이 모두 양수일 때만 유효합니다.

❌ 치명적 실수

실수 전체 $x$에 대해 $x + \frac{1}{x} \ge 2\sqrt{x \cdot \frac{1}{x}} = 2$ ?

$x = -3$이면 $-3 - \frac{1}{3} = -3.33 \dots$ 이므로 2보다 훨씬 작습니다! ($x>0$ 조건 필수)
✓ 문자나 식이 정의된 구간이 양수인지 먼저 확인하라
02
상수화 원칙

곱(또는 합)이 일정한 상수인가?

합의 최솟값을 구할 때는 곱 $AB$가 '상수'여야 합니다.

❌ 치명적 실수

$x^2 + (4-x)^2 \ge 2\sqrt{x^2(4-x)^2} = 2|x(4-x)|$

우변이 $x$에 따라 요동치는 식이므로, 이를 '최솟값'이라 부를 수 없습니다!
✓ 우변의 변수가 완벽히 소거되어 고정된 상수가 되는지 확인하라
03
등호 성립 검증

등호 성립 조건 ($A=B$)이 실재하는가?

부등식을 성립시키는 $A=B$인 변수 값이 실제 정의역에 존재하는가?

❌ 치명적 실수

부등식을 두 번 연속 쓸 때, 두 등호 조건이 서로 충돌하는 경우

$a=b$여야 하는데 동시에 $a=4b$여야 한다면 양수에서는 절대 불가능합니다!
✓ 부등식을 여러 번 쓸 땐 등호가 '동시에' 만족되는지 점검하라

심층 분석 사례 1 등호 성립 조건의 동시성 모순

두 양수 $a, b$에 대하여 $\frac{8}{a} + \frac{2}{b} = 1$일 때, $a+b$의 최솟값은?

가장 많은 학생들이 오답인 16을 적어 내는 대표적인 고난도 함정 문제입니다. 왜 16이 될 수 없고, 진짜 최솟값은 18인지 인터랙티브 시뮬레이터로 확인해보세요.

대표적인 잘못된 풀이 (오답: 16)
Step 1

두 식에 각각 산술·기하평균을 적용합니다.

$$a + b \ge 2\sqrt{ab} \quad \cdots\text{ (1)}$$ $$1 = \frac{8}{a} + \frac{2}{b} \ge 2\sqrt{\frac{16}{ab}} = \frac{8}{\sqrt{ab}} \quad \cdots\text{ (2)}$$
Step 2

(2)식에서 $\sqrt{ab}$의 범위를 구합니다.

$$1 \ge \frac{8}{\sqrt{ab}} \implies \sqrt{ab} \ge 8$$
Step 3

이를 (1)식에 대입하여 최솟값을 결론짓습니다.

$$a + b \ge 2\sqrt{ab} \ge 2 \times 8 = 16 \quad \text{?!}$$
⚠️ 왜 치명적인 오류인가?

(1)식의 등호 성립 조건은 $a = b$ 입니다.
(2)식의 등호 성립 조건은 $\frac{8}{a} = \frac{2}{b}$, 즉 $a = 4b$ 입니다.

$$a = b \text{ 이면서 동시에 } a = 4b \implies b = 4b \implies b = 0, a = 0$$

하지만 문제에서 $a, b$는 양수($a>0, b>0$)라고 하였습니다.
따라서 $a+b$가 16이 되는 순간은 세상에 존재하지 않습니다!

올바른 풀이 (정답: 18)
방법 1 곱 전개법 (상수 1 곱하기)

주어진 조건 $\frac{8}{a} + \frac{2}{b} = 1$을 $(a+b)$에 곱하여 전개합니다.

$$(a+b) = (a+b)\left(\frac{8}{a} + \frac{2}{b}\right)$$ $$= 8 + 2 + \frac{2a}{b} + \frac{8b}{a} = 10 + \left(\frac{2a}{b} + \frac{8b}{a}\right)$$
방법 2 역수 쌍에 산술·기하평균 1회 적용

문자가 완벽히 약분되어 상수가 됩니다!

$$\frac{2a}{b} + \frac{8b}{a} \ge 2\sqrt{\frac{2a}{b} \cdot \frac{8b}{a}} = 2\sqrt{16} = 8$$ $$\therefore (a+b) \ge 10 + 8 = 18$$
검증 등호 성립 조건 확인
$$\frac{2a}{b} = \frac{8b}{a} \iff a^2 = 4b^2 \iff a = 2b \quad (a, b > 0)$$ $$\frac{8}{2b} + \frac{2}{b} = 1 \iff \frac{6}{b} = 1 \iff \mathbf{b = 6, a = 12}$$

$a=12, b=6$일 때 $\frac{8}{12} + \frac{2}{6} = \frac{2}{3} + \frac{1}{3} = 1$ 만족!
이때 $a+b = 12 + 6 = \mathbf{18}$로 실제 최솟값이 달성됩니다!

실시간 시뮬레이터

곡선 $\frac{8}{a} + \frac{2}{b} = 1$ 과 $a+b$의 변화 탐색

조건 곡선: $b = \frac{2a}{a-8}$ ($a>8$) $a+b = k$ (탐색선) $a+b = 16$ (오답선 - 곡선과 만나지 않음!) 최적점 $(12, 6)$
12.0
$a \to 8^+$ $a = 12$ (최솟값) $a = 32$

📊 현재 점 $(a, b)$의 상태

$a$의 값: 12.00
$b = \frac{2a}{a-8}$ 의 값: 6.00
$a + b$ 의 실제 합: 18.00
오류 풀이의 하한값: 16.00 (절대 도달 불가)
💡
시각적 통찰: 직선 $a+b=16$은 조건 곡선(쌍곡선)보다 항상 아래쪽에 위치하여 곡선과 단 한 점도 만나지 않습니다! 직선 $a+b=k$를 평행이동하며 곡선과 접하는 가장 낮은 위치를 찾으면 바로 $k=18$, 접점은 $(12, 6)$입니다.
심층 분석 사례 2 우변이 상수가 아닌 경우의 함정

$x^2 + (4-x)^2$의 최솟값을 산술·기하평균으로 풀면 생기는 오류

"두 항을 더했으니 산술기하를 쓰면 되겠지?"라는 기계적인 공식 대입이 왜 위험한지 알아봅니다. 우변이 고정된 상수가 아니라 $x$에 따라 요동치는 함수일 때 어떤 일이 일어나는지 그래프로 직관적으로 확인하세요.

잘못된 산술·기하평균 접근법
Step 1

아무 생각 없이 두 항을 곱하여 산술기하평균을 씁니다.

$$x^2 + (4-x)^2 \ge 2\sqrt{x^2(4-x)^2} = 2|x(4-x)|$$
Step 2

등호 성립 조건 $x^2 = (4-x)^2 \implies x = 2$를 대입하여 계산합니다.

$$x=2 \text{ 일 때 } 2|2(4-2)| = 8 \implies \text{최솟값 8 ?}$$
⚠️ 왜 우연의 일치이며 수학적으로 틀린 논리인가?
  • 1. 우변 $2|x(4-x)|$는 상수가 아닙니다!
    부등식 $f(x) \ge g(x)$는 단지 $f$가 $g$ 위에 있다는 뜻일 뿐, $g(x)$의 값이 $f(x)$의 최솟값이 되려면 $g(x)$가 일정한 상수 $C$여야 합니다.
  • 2. 양수 조건 미확인:
    $x$가 0보다 작거나 4보다 크면 $x$와 $4-x$의 부호가 달라지므로, 산술기하의 기본 전제인 두 수의 양수성이 파괴됩니다.
  • 3. 다른 식에 적용하면 100% 오답:
    예를 들어 $(x-1)^2 + (x-3)^2$에 동일한 논리를 쓰면 완전히 틀린 엉터리 값이 나옵니다!
올바른 풀이 (이차함수 표준형 변형)
Step 1 다항식 전개 및 정리

식을 전개하여 $x$에 대한 2차 다항식으로 정리합니다.

$$f(x) = x^2 + (16 - 8x + x^2) = 2x^2 - 8x + 16$$
Step 2 완전제곱식(이차함수 꼭짓점) 변형
$$f(x) = 2(x^2 - 4x + 4) - 8 + 16$$ $$= 2(x-2)^2 + 8$$
결론 실수의 성질을 이용한 최솟값 확정
$$\text{모든 실수 } x \text{에 대하여 } (x-2)^2 \ge 0 \text{ 이므로,}$$ $$f(x) \ge 0 + 8 = \mathbf{8}$$

등호는 $(x-2)^2 = 0$, 즉 $x = 2$일 때 성립합니다.
우변이 명확한 상수 8이므로 $f(x)$의 최솟값은 8입니다!

실시간 그래프 시각화

$f(x) = x^2 + (4-x)^2$ 와 $g(x) = 2|x(4-x)|$ 의 관계 분석

원래 함수 $f(x) = 2x^2 - 8x + 16$ 잘못 적용한 하한식 $g(x) = 2|x(4-x)|$ 실제 최솟값 상수선 $y = 8$ 현재 $x$에서의 점 $P(x, f(x))$ 와 $Q(x, g(x))$
2.00
$x = -1.0$ $x = 2.0$ (꼭짓점) $x = 5.0$

📊 현재 $x$에서의 함수값 비교

원래 함수 $f(x)$: 8.00
산술기하 우변 $g(x)$: 8.00
두 곡선 사이의 간격 $f(x) - g(x)$: 0.00
진짜 최솟값 (상수): 8.00 (불변)
🔍
그래프가 말해주는 진실: 슬라이더를 움직여보세요! $x$가 변할 때 $g(x)$ 곡선은 0부터 8까지 요동칩니다. $f(x) \ge g(x)$는 항상 성립하지만, $g(x)$의 값이 상수가 아니라 춤추고 있으므로 $g(x)$를 기준으로는 $f(x)$가 어디까지 내려갈 수 있는지(최솟값)를 결코 알 수 없습니다.
